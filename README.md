## 🛡️ ThreatLens AI

A real-time web threat intelligence dashboard powered by 
Machine Learning — detect SQL Injection, XSS, Bot attacks, 
and Path Traversal directly from your server logs.

## 🚀 Features
- Real-time threat detection from Apache/Nginx logs
- ML-powered anomaly scoring (Isolation Forest)
- Live dashboard with charts and threat feed
- Attack categorization by type, IP, and severity

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | React + Vite + Tailwind CSS |
| Backend | Node.js / Python FastAPI |
| ML Model | Isolation Forest (scikit-learn) |
| Charts | Recharts |

## ⚙️ Getting Started
git clone https://github.com/Ishantsingh2812/threatlens-ai
cd threatlens-ai
npm install
npm run dev
